Who makes these

One engineer, working in the open

Island Forge is a one-person operation. I build and maintain data and machine learning systems — model serving, orchestration, CI/CD, the unglamorous parts that decide whether a model is useful or merely impressive.

These tools exist because I needed them. The quality gate in BookForge is there because a run of books shipped with placeholder covers. The dedup memory in DesignForge is there because a catalogue filled up with near-identical work. Every awkward-looking guard rail marks something that already went wrong once.

Day to day I work with Python, Go and C#; Kubernetes, Helm, Terraform, Docker; KServe, Kubeflow, Airflow, Dagster, Tekton and ArgoCD; PyTorch and the usual model-serving stack; Postgres and MongoDB; React on the front end.
