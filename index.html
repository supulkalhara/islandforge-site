Buy the bundle

Your machine, your data

Nothing here runs on my servers, because there are none.

Every tool talks only to endpoints you configure yourself. No account, no telemetry, no licence check that phones home. You get two ways to run them, and you pick per tool.

Option A

On your own machine

Download an open model once, then run everything locally. Your briefs, manuscripts, designs and output never leave the computer. After the download there is no per-run cost and, for most of these tools, no network call at all.

On a Mac that means Ollama for text, and for images either Draw Things (one settings toggle, then all terminal) or a pure command-line generator like draw-things-cli or mflux. Each tool ships a setup guide naming the exact model to download and the settings to change.

Ollama · qwen2.5:14b ≈ 9 GB · nomic-embed-text ≈ 274 MB · FLUX.1 Schnell ≈ 7 GB or SDXL 8-bit ≈ 3.5 GB · 16 GB RAM comfortable

Option B

An endpoint you already trust

Do not want a 9 GB download, or already run a gateway? Set an API base and key and the tool switches to the OpenAI-compatible protocol. Works with OpenAI, Azure OpenAI, Together, Groq, OpenRouter, a self-hosted vLLM, or your own LiteLLM router.

Your prompts go to the endpoint you named, and nowhere else

BookForgeFully offline once models are on disk. Nothing leaves the machine.
DesignForgeFully offline once models are on disk. The dedup memory is a local file.
PainScoutFetches the public RSS feeds you list, because reading them is the job. Scoring can stay entirely local.
ReelForgeOffline if you skip the voiceover. Finished videos are never uploaded anywhere.
ShipKitTalks to Gumroad by design, using a token you created. No model involved at all.

Every tool prints where its model actually lives when you run doctor, so you are never guessing which of the two you are on.

Who makes these

Island Forge is a one-person operation. I build and maintain data and machine learning systems. Model serving, orchestration, CI/CD, the unglamorous parts that decide whether a model is useful or merely impressive.

These tools exist because I needed them. The quality gate in BookForge is there because a run of books shipped with placeholder covers.
